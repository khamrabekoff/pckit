# pckit by odilbek

Бесплатная программа для Windows 10/11: ускорить ПК для игр (CS2/FACEIT-безопасно), почистить мусор, режим «Для работы» (офис, Photoshop, AutoCAD, Revit), проверка ПК, сети и драйвера NVIDIA. Все изменения пишутся в журнал и отменяются кнопкой «Вернуть как было».

## Как запустить

1. Откройте [Releases](../../releases/latest) и скачайте файл **pckit-by-odilbek.cmd**.
2. Запустите его двойным щелчком.
3. На вопрос Windows «Разрешить изменения?» нажмите **Да**.
4. Если появится «Windows защитила ваш компьютер» — **Подробнее → Выполнить в любом случае** (файл без цифровой подписи).

Ничего устанавливать не нужно: используется встроенный PowerShell 5.1.

## Кнопки на главной

- **Ускорить для игр** — начните с неё: безопасные настройки под ваш ПК, чистка и подсказки, что сделать руками.
- **Максимальное ускорение** — то же плюс экспертные настройки (службы, телеметрия, индексация). Перед применением покажет, что из этого с риском и чем платите.
- **Для работы** — для офиса, Photoshop, AutoCAD, Revit.
- **Почистить диск** и **Проверить ПК** — по отдельности.
- **Вернуть как было** — отменяет всё, что сделал pckit.

## Для разработчика

- `pckit-ui.ps1` — окно программы, `engine\` — логика, `data\` — список настроек.
- Сборка одного файла: `powershell -ExecutionPolicy Bypass -File build.ps1` → `dist\pckit-by-odilbek.cmd`.
- Тесты: `tests\*.Tests.ps1`.
- Подробности — в [PCKIT.md](PCKIT.md).
