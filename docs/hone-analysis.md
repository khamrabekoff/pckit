# Разбор оптимизатора Hone (идеи для pckit)

Дата разбора: 2026-11-05. Версия Hone: 2.1.0 (по имени лога). Издатель подписи: AuraSide, Inc.
Метод: статический разбор `app.asar` инструментом rea 6.8.0 (`analyze-javascript-application`, только чтение) + чтение файлов в папке установки и журналов, которые Hone сам оставил на этом ПК. Hone не запускался и не менялся. Код, тексты и оформление Hone в pckit не переносятся — ниже только перечень идей, формулировки наши.

## 1. Что это за программа
- Electron-приложение (главный процесс `main.js` ≈3 МБ, 107 JS-файлов, 1 нативный аддон) + набор своих exe-помощников в `resources\assets\hone-resources`.
- Сами твики (значения реестра, команды) в клиенте как текст не лежат: в `app.asar` только каталог названий и описаний (≈100 пунктов), а наборы изменений, вероятно, приходят с сервера hone.gg и исполняются нативными помощниками (HoneUtility.exe, TotalReg.exe, reg.exe, SetTimerResolution.exe, NVIDIA Profile Inspector и профили `.nip`/`.pow`). Поэтому **точный список изменений реестра даст только снимок «до/после» (шаг 2)**.

## 2. Функции Hone
| Блок | Что делает |
|---|---|
| Оптимизации | каталог ≈100 твиков, применить/откатить, «нравится/не нравится», бесплатные и платные |
| Игровой режим (Game Mode) | запуск/остановка профиля при старте игры, список обнаруженных игр (манифест ≈20 МБ) |
| Игровые настройки | пресеты «оптимальный/производительный», настройки pro-игроков, NVIDIA-профили для игр |
| Очистка | «junk cleaner», кэш Discord, кэш шрифтов |
| BIOS | чтение/запись настроек BIOS (`hone-bios.exe`, раздел «BIOS Optimizations») — самая рискованная часть |
| Бенчмарк / проверка | `HoneBenchmarkHost`, «System Validator»: проверка ОС, ожидающей перезагрузки, антивируса, брандмауэра, конфигурации Defender, процессов и служб |
| Мониторинг железа | HWiNFO SDK (датчики) |
| Прочее | трей-значок, уведомления, сброс DPI/разрешения таймера, замена Диспетчера задач на Process Explorer и regedit на Total Registry |

## 3. Каталог твиков Hone (по смыслу)
**Система/питание:** план электропитания (в комплекте свои `.pow`: Balanced / HighPerformance / HoneV5); отключить Power Throttling; отключить «энергосберегающие» функции; гибернация; разрешение таймера; I/O; память (менеджер памяти); BCDEdit; CSRSS (приоритет); MSI-прерывания устройств; привязка устройств к ядрам (affinity); «CPU на 100%» (заблокировать простой); оптимизация дисков; задачи планировщика; службы Windows (отключение «лишних»); Superfetch/SysMain; поиск Windows (индексатор); Program Compatibility Assistant.
**Игры/графика:** Game Bar; полноэкранные оптимизации; MPO (многоплоскостное наложение); NVIDIA: Control Panel/Inspector-профиль, общие твики, HDCP, «фиксированные максимальные частоты», старая резкость, телеметрия; AMD-настройки; Intel iGPU; драйвер NVMe Samsung.
**Сеть:** TCP, Netsh, congestion provider, DSCP, свойства сетевого адаптера, task offload, снятие лимита пропускной способности, SMBv1/v2, отключение Wi-Fi/Bluetooth/VPN-поддержки.
**Ввод:** мышь (1:1, без ускорения), параметры доступности (Sticky Keys и др.).
**Приватность:** DiagTrack, телеметрия Windows Update/Store, панели задач и «Пуска», Chrome/Edge/Firefox/Office/Visual Studio/NVIDIA/«80+ dev-приложений», ошибки Windows (WER), программа предварительной оценки, Cortana, Copilot, реклама в Параметрах.
**Интерфейс:** прозрачность, визуальные эффекты, классическое меню Win11, старый Alt-Tab, старый регулятор громкости, автозапуск эффектов, «Focus Assist», блокировка экрана и размытие, подсказки поиска, часто используемые элементы, значки трея и др.
**Приложения:** OneDrive; браузерная аппаратная акселерация; фон браузера; обновления браузеров; Xbox; My People; HomeGroup; факс/печать; сенсорный ввод.
**Опасные пункты (в самом каталоге Hone помечены как небезопасные или спорные):** отключить Defender; отключить UAC; отключить SmartScreen; отключить VBS; «Disable Mitigations» (защиты процессора и ядра).

## 4. Сеть: что Hone отправляет и куда
- **hone.gg** (сайт, API, `app`, `game-mode`, `redeem`) — лицензия, каталог, обновления наборов.
- **Mixpanel** (`api-js.mixpanel.com`, `cdn.mxpnl.com`, в том числе скрипт **записи сессий** `mixpanel-recorder`) — аналитика использования; при удалении отправляется событие `hone_uninstalled` с идентификатором пользователя.
- В коде есть ссылки на документацию Sentry (возможна отправка отчётов об ошибках — не подтверждено), **Overwolf** (`electron-updates.overwolf.com`) — обновления; Discord (чат/кэш); Google Forms (обратная связь).
- Исходящие запросы делает ещё `HttpClient.exe` (в `assets`).
- Журналы валидатора содержат сведения о ПК (процессор, ядра, антивирус, брандмауэр, состояние Defender) — нужно проверять, уходит ли это на сервер (по тексту клиента: «чтобы сравнивать результаты бенчмарка»). Заявление проверить трафиком нельзя без отдельной проверки — **отметить как риск приватности**.

## 5. Отдельные риски (что НЕ берём в pckit)
1. **Драйвер ядра.** Через HWiNFO SDK Hone ставит драйвер `HWiNFO_x64_216.sys` (сейчас на этом ПК он **запущен**, режим «persistentDriver=enabled»). Драйверы сторонних датчиков и читающие память — зона риска для античитов (FACEIT/VAC). pckit этого не делает.
2. **Служба и повышенные права.** `hone-elevation-helper.exe` (проверяет подпись клиента, выполняет команды `run`/`kill` от администратора), `HoneSvc.exe`, задача планировщика `LaunchHone`. Любая программа с такой схемой получает полный контроль над ПК.
3. **Записи в BIOS** (`hone-bios.exe`) — риск неработающей системы.
4. **Отключение защиты Windows:** Defender, UAC, SmartScreen, VBS, митигации — прямо противоречит правилам проекта.
5. **Установка чужих компонентов:** драйвер NVMe Samsung, Process Explorer, Total Registry, nvidiaProfileInspector, 7-Zip, HWiNFO.
6. **Ограничения откатываемости:** часть пунктов (BIOS, драйвер NVMe, сеть/Netsh) возвращается не обычным откатом.
7. **Приватность:** постоянный идентификатор пользователя + аналитика с записью сессий.

## 6. Что проверено, а что нет
- Подтверждено: тип приложения, состав, каталог названий/описаний, адреса сервисов, наличие драйвера/службы/задачи, чтение антивируса и Defender валидатором.
- **Не подтверждено:** какие именно ключи реестра, службы и значения powercfg записывает каждая оптимизация. Будет добавлено после шага 2 (`tools\pckit-diff.ps1`, снимок до/после; запускаете Hone вы).
