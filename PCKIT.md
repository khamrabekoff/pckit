# pckit by odilbek

Выбираете, что сохранить с этого компьютера, получаете один файл `*.pckit`, после переустановки Windows запускаете его — программа возвращает приложения, данные и настройки.

Статус: **готово** — простой и экспертный режимы, восстановление, игры с точкой восстановления, чистка, проверка ПК, экран «Сделано» и один файл для отправки.

## Два режима

По умолчанию открывается **«Просто»** — четыре карточки, ничего лишнего:

| Карточка | Что делает |
|---|---|
| ⚡ **Ускорить компьютер** | применяет рекомендуемые игровые настройки (высокий и средний эффект), показывает список до подтверждения |
| 🧹 **Почистить** | считает безопасные кэши, показывает сумму, удаляет после подтверждения |
| 💾 **Сохранить настройки** | собирает приложения и настройки в один файл `*.pckit` |
| 🩺 **Проверить** | запускает проверку ПК и показывает, что не так |

Сверху — строка состояния: «Компьютер в порядке» или «Замечаний: 1 — ничего критичного». Она считается сама через 1,5 секунды после запуска.

Ссылка **«Все настройки →»** в правом верхнем углу открывает **экспертный режим** — все семь вкладок (Просто, Сохранить, Вернуть, Вручную, Игры, Чистка, Отчёт). Обратно — ссылка «Простой режим →».

## Окно

Запуск: двойной щелчок по `pckit-ui.cmd` (или `.\pckit-ui.ps1`). Программа сразу запрашивает права администратора — без них нельзя чистить систему и менять настройки. Три вкладки.

**Сохранить** — что взять с этого ПК:

- слева дерево по группам: программы, данные приложений, файлы, настройки Windows, сеть, разработка;
- галочка = сохранить; в строке виден размер, красным — рискованные пункты;
- справа — что именно копируется (пути, реестр, команды);
- сверху — поиск и набор: «Минимум / Работа / Всё»;
- снизу — «Выбрано: N объектов · примерно X ГБ», кнопки «Ничего», «Всё», «Обновить», «Собрать профиль...».

**Вернуть** — восстановление на чистой системе, без консоли:

1. «Открыть профиль...» → выбрать `*.pckit`;
2. появится план: `install` (поставить), `copy` (скопировать), `manual` (вручную), `timezone`/`wifi`/… (настройки);
3. галочка «пробный прогон» включена по умолчанию — снимите её, чтобы применить по-настоящему;
4. «Применить» → прогресс по шагам, в колонке «Результат» статус каждого шага, внизу путь к логу и папке бэкапов.

**Вручную** — 20 карточек программ без пакета winget: производитель, что учесть после переустановки, ссылка на загрузку (двойной щелчок открывает), отметка «на этом ПК».

Каталог кэшируется в `state\catalog.json`, поэтому окно открывается сразу; «Обновить» — пересканировать.

## Быстрый старт

```powershell
# 1. Посмотреть, что вообще есть на машине (ничего не меняет)
.\pckit.ps1 scan

# 2. Собрать профиль: пресет work = приложения + настройки ОС + данные с низким риском
.\pckit.ps1 pack -Preset work -Out "F:\PC-BACKUP\my.pckit" -Name "мой ПК"

# 3. Убедиться, что план выглядит разумно (ничего не меняет)
.\pckit.ps1 plan -Profile "F:\PC-BACKUP\my.pckit"

# 4. На ЧИСТОЙ системе: сначала dry-run, потом реальный запуск
.\pckit.ps1 apply -Profile "F:\PC-BACKUP\my.pckit"
.\pckit.ps1 apply -Profile "F:\PC-BACKUP\my.pckit" -Run

# 5. Проверка: что вернулось, что осталось руками
.\pckit.ps1 verify -Profile "F:\PC-BACKUP\my.pckit"
```

## Команды

| Команда | Что делает | Меняет систему |
|---|---|---|
| `scan` | собирает каталог: приложения, данные, ОС, сеть, dev-инструменты | нет |
| `pack` | упаковывает выбранное в `*.pckit` (zip: manifest + payload + checksums) | нет |
| `plan` | показывает план восстановления | нет |
| `apply` без `-Run` | dry-run: что было бы сделано | нет |
| `apply -Run` | выполняет: winget install, копирование, реестр, настройки | **да** |
| `verify` | проверяет результат и печатает «осталось руками» | нет |
| `undo` | показывает, что можно отменить (журнал изменений) | нет |
| `undo -Run` | отменяет: файлы из бэкапа, параметры реестра к прежним значениям | **да** |
| `health` | проверяет ПК, печатает отчёт и сохраняет его в `Documents\pckit\Отчёты` | нет |

### Пресеты

| Пресет | Что выбирает |
|---|---|
| `minimal` | приложения с winget-пакетом + основные настройки ОС (таймзона, языки, схема питания, hosts) |
| `work` | minimal + данные приложений с низким и средним риском + Рабочий стол и Документы + gitconfig и переменные среды |
| `all` | всё, что существует на машине (кроме драйверов — им нужен администратор) |

### Фильтры

```powershell
.\pckit.ps1 pack -Preset minimal -Include "appdata:chrome,appdata:obs"
.\pckit.ps1 pack -Preset work    -Exclude "files.downloads,appdata:telegram"
.\pckit.ps1 pack -Preset minimal -Include "app:adobephotoshop*"   # шаблоны по Id или названию
```

## Что попадает в профиль

```
my.pckit (zip)
├── manifest.json       # выбранные объекты, отпечаток машины, список «руками»
├── payload/            # данные: appdata/…, files/…, wifi/*.xml, os/hosts, dev/…
└── checksums.sha256    # SHA-256 каждого файла payload
```

Типы объектов: `app` (winget / вручную / Store), `appdata` (по рецепту), `files` (папки; режим `copy` или `reference`), `os` (таймзона, языки, питание, hosts, задачи, принтеры, драйверы), `network` (Wi-Fi, сетевые диски), `dev` (git, переменные среды, npm, pip, dotnet, VS Code, WSL).

## Рецепты

Рецепт — JSON-файл в `recipes\`, описывающий, где приложение хранит данные:

```json
{
  "id": "vlc",
  "title": "VLC media player",
  "risk": "low",
  "match": { "displayName": "^VLC media player", "winget": "VideoLAN.VLC" },
  "steps": [
    { "type": "dir", "path": "%APPDATA%\\vlc", "exclude": ["cache", "*.log"] }
  ]
}
```

Типы шагов: `dir`, `file`, `registry` (экспорт/импорт ветки), `command` (список + шаблон установки), `note`.

Правила:
- пути раскрываются (`%APPDATA%`, `~`);
- валидатор блокирует `C:\Windows`, `Program Files`, корни дисков и целые `%APPDATA%`/`%USERPROFILE%`;
- `exclude` — имена папок/файлов или маски (`*.log`), кэши не копируются.

Добавить поддержку приложения = положить новый JSON в `recipes\`. Код менять не нужно.

Сейчас поддерживаются: Chrome, Edge, VS Code (+ расширения), Telegram, OBS, VLC, WinRAR, 7-Zip, Git, Node.js, Obsidian, Thunderbird.

## Окно

Светлый стиль Windows 11: меню слева (Главная, Игры, Чистка, Автозагрузка, Результат, Проверка, Сделано; группа «Перенос на новую Windows»: Сохранить, Вернуть, Вручную), белые скруглённые карточки, иконки из шрифта Segoe MDL2 Assets (есть в Windows 10 и 11). Простого/экспертного режима больше нет. Заголовки вкладок `TabControl` скрыты — логика вкладок осталась прежней.

## Автозагрузка

Раздел «Автозагрузка» (`engine\Startup.ps1`): программы из `Run` (HKCU, HKLM, WOW6432Node) и папок «Автозагрузка». Издатель берётся из exe, совет: «нужно» (драйверы, античиты FACEIT/Vanguard/EAC, защита Windows, утилиты мыши и звука), «можно отключить» (лаунчеры, мессенджеры, браузеры, облака), «на ваше усмотрение».
Отключение — тем же способом, что в Диспетчере задач (`Explorer\StartupApproved`, 12 байт: `03` + время), запись в Run не удаляется. Каждое изменение пишется в журнал и отменяется в «Сделано». Перед первым отключением делается замер «до» — эффект виден в «Результате».

## Результат «до/после»

Вкладка «Результат» и карточка «📊 Результат» на главной. Перед первыми изменениями («Ускорить», «Почистить», «Применить» в «Играх») программа сама делает замер «до» (~20 с); «Результат» делает замер «после» и сравнивает.

Что меряется (`engine\Snapshot.ps1`): свободное место, элементы автозагрузки, процессы, запущенные службы, загрузка CPU / DPC / прерывания / ОЗУ в простое (медиана по 8 замерам), время загрузки Windows (журнал Diagnostics-Performance, событие 100), пинг и джиттер до 1.1.1.1 и 8.8.8.8, схема питания.
Честность: точные числа (место, автозагрузка) — «лучше/хуже»; шумные (CPU, ОЗУ, DPC) — «в пределах шума», если разница меньше разброса замеров; время загрузки — «нужна перезагрузка», пока ПК не перезагрузили; пинг — только контроль. HTML-отчёт: `Documents\pckit\Отчёты\Сравнение-*.html`, снимки — `%LOCALAPPDATA%\pckit\snapshots`.

**FPS в CS2** (`engine\PresentMon.ps1`) — по желанию: Intel PresentMon (MIT) скачивается только после согласия, с официального релиза GitHub, с проверкой подписи Intel, в `%LOCALAPPDATA%\pckit\tools`. Замер 60 с: средний FPS, 1% low, 0.1% low, p99 времени кадра. Только вне матчей FACEIT (практика, боты, демка).

CLI: `.\pckit.ps1 snapshot -Name до`, `.\pckit.ps1 compare`.

## Игры (CS2)

Вкладка «Игры» — 32 пункта: 21 обычная настройка, 5 экспертных (⚠ службы и задачи Windows: SysMain, телеметрия, Xbox, поиск — по умолчанию не отмечаются, перед применением отдельное предупреждение) и 6 мифов (Nagle, «20% канала», bcdedit/HPET, чистка Prefetch, «очистка ОЗУ», «все ядра в msconfig») — их нельзя отметить, они объясняют, почему это не работает.
Новые типы шагов в `actions.json`: `regkv` (параметр внутри строки `a=1;b=2;`), `service`, `task`, `powercfg` (на активной схеме, от сети и от батареи), `hibernate`, `netpower`; поля `expert`, `myth`, `minBuild`, `note`. Всё пишется в журнал и откатывается. «Рекомендуемые» = высокий/средний эффект, без экспертных и мифов.

Исходные 9 действий:

| Действие | Эффект |
|---|---|
| Схема питания «Максимальная производительность» | высокий |
| Отключить ускорение мыши | высокий (для стрельбы) |
| Отключить Game DVR | средний |
| Приоритет игр в планировщике (MMCSS) | средний |
| Отключить Power Throttling | средний |
| Включить игровой режим Windows | низкий |
| Не раздавать обновления Windows другим | низкий |
| Отключить залипание клавиш | низкий |
| Снять лимит сетевого троттлинга | низкий (честно: чаще не даёт ничего) |

Кнопки: **«Отметить рекомендуемые»** (высокий и средний эффект), **«Применить отмеченные»**, **«Проверить»** (перечитать состояние), **«Отменить изменения»** (журнал), галочка **«только показать»** — холостой прогон.

Перед применением по умолчанию стоит галочка **«точка восстановления»**: программа просит Windows создать точку, чтобы можно было откатиться даже если что-то пойдёт не так на уровне системы. Windows создаёт точки не чаще раза в сутки — если свежая уже есть, программа так и скажет.

Действия лежат в `data\actions.json` — их можно править без кода:

```jsonc
{
  "id": "gamedvr.off",
  "title": "Отключить Game DVR",
  "what": "Windows перестаёт писать последние секунды игры в фоне.",
  "effect": "Меньше нагрузки на диск, иногда +1–3% fps.",
  "effectLevel": "средний",
  "risk": "low",
  "steps": [ { "type": "reg", "path": "HKCU:\\System\\GameConfigStore", "name": "GameDVR_Enabled", "value": 0, "valueType": "DWord" } ],
  "verify": [ { "type": "reg", "path": "HKCU:\\System\\GameConfigStore", "name": "GameDVR_Enabled", "value": 0 } ]
}
```

Типы шагов: `reg` (параметр, пишется через журнал) и `powerplan` (схема питания, откат — прежняя схема).

## Чистка

Вкладка «Чистка» — до 27 целей (цели программ появляются, только если программа есть на ПК): временные файлы программ и Windows, кэш обновлений, кэш доставки обновлений,
отчёты о падениях, дампы, кэш браузеров (Chrome, Edge, Brave, Opera/GX, Yandex, Vivaldi — все профили; Firefox), Discord, Steam (веб-кэш, логи), Epic, Battle.net,
миниатюры Проводника, журналы обслуживания Windows, сжатие WinSxS (штатный DISM, без /ResetBase), кэши pip/npm/NuGet, Windows.old (только показывает размер и открывает Параметры), кэш шейдеров NVIDIA / DirectX / AMD / Steam, корзина.
Кэши шейдеров теперь «средний риск»: после очистки первые катки подлагивают, поэтому быстрая чистка их не трогает. Быстрая чистка с главной не трогает также DISM и кэши разработчика.
Не чистим намеренно: Prefetch и журналы событий (это вредит, а не ускоряет).

- **сначала «Посчитать»** — показывает размер каждой цели и общий итог;
- **«Отметить безопасное»** — ставит галочки на всё с низким риском;
- **«Очистить отмеченное»** — подтверждение с итоговым размером, затем удаление;
- удаляется только **содержимое** кэшей, сами папки остаются; занятые файлы пропускаются;
- удаление необратимо, поэтому корзина помечена как «средний риск» и включена отдельно.

На рабочем ПК нашлось 1,2 ГБ (433 МБ дампов, 325 МБ кэша Chrome, 221 МБ Edge, 142 МБ шейдеров NVIDIA).

## Один файл

`.\build.ps1` (проверяет синтаксис, BOM и JSON, затем собирает из `build\loader.template.cmd`) собирает **dist\pckit-by-odilbek.cmd** (~160 КБ) и `dist\README.txt` с контрольной суммой. Тесты движка: `tests\*.Tests.ps1` — один файл, который можно отправить и запустить двойным щелчком.

Как он работает: файл распаковывает себя в `%LOCALAPPDATA%\pckit\app-<хэш>` и запускает окно с правами администратора.
Новая версия — новый хэш — рядом появляется новая папка, старая не ломает запуск.

Полезно знать:

- `set PCKIT_NO_LAUNCH=1` перед запуском — только распаковать, без открытия окна (диагностика);
- внутри архива: `engine\` (11 модулей), `recipes\` (12 рецептов), `data\` (действия и карточки), окно, CLI и этот файл;
- антивирус может спросить про «неизвестный файл» — это обычный .cmd, исходники лежат рядом в папке проекта.

## Сделано

Вкладка «Сделано» — список всего, что программа изменила в системе: когда, что именно и что было до этого.

- берётся из журнала `%ProgramData%\pckit\undo.json`;
- кнопка **«Отменить всё»** возвращает файлы из бэкапа и параметры реестра к прежним значениям;
- кнопка **«Обновить»** перечитывает журнал.

## Отчёт

Вкладка «Отчёт» — проверка компьютера, которая **ничего не меняет**.

Что проверяется:

- память: одна планка или нечётное число → часть памяти в одноканале (минус 5–15% fps); разные частоты планок;
- место на системном диске (меньше 20% — предупреждение, меньше 10% — проблема);
- схема питания, Game DVR, приоритет игр в планировщике, ускорение мыши — со ссылкой на действие во вкладке «Игры»;
- возраст драйвера видеокарты (старше 8 месяцев — предупреждение);
- незавершённая перезагрузка Windows;
- размер временных файлов, число программ в автозагрузке;
- включена ли изоляция ядра (VBS/HVCI) — только сообщаем, не трогаем;
- найдена ли CS2 и где она лежит;
- сколько изменений лежит в журнале отката.

Кнопки: **«Проверить ПК»**, **«Сохранить отчёт»** (HTML-файл в `Documents\pckit\Отчёты` — открывается в браузере, удобно отправить с телефона), **«Перейти к исправлению»** — если у находки есть действие, программа переключится на «Игры» и отметит нужный пункт.

Ещё: в заголовке — сводка по железу (CPU · память · видеокарта · место на диске), внизу — строка «что делать» для выбранной находки.

## Журнал изменений

Каждое изменение, которое делает программа, записывается в `%ProgramData%\pckit\undo.json`:

- **файлы** — что заменено и где лежит бэкап;
- **ветки реестра** — копия `.reg` до импорта;
- **параметры** — исходное значение и тип (или отметка «его не было»);
- **команды** — например, прежняя схема электропитания и часовой пояс.

Откат (`undo -Run` или кнопка «Отменить изменения» в окне) возвращает всё в обратном порядке. Если всё прошло без ошибок, журнал очищается; если что-то упало — записи остаются, чтобы повторить.

## Безопасность

- **dry-run по умолчанию**: `apply` без `-Run` ничего не меняет.
- **перед перезаписью** существующий файл/папка переносится в `state\backups\<дата>\`.
- **логи**: `state\logs\apply-<дата>.log`.
- **ничего не удаляется** без явного действия; `copy` только добавляет/перезаписывает.
- **секреты не переносятся**: пароли браузеров зашифрованы DPAPI и на другой машине не откроются — это указано в рецептах и в отчёте.

## Ограничения

- Store-приложения попадают в профиль одним пунктом-списком (ставятся из Store вручную);
- драйверы выгружаются только при запуске от администратора;
- `os.tasks`, `os.printers`, `os.mappeddrives` сохраняются как список для ручного восстановления;
- Wi-Fi-профили экспортируются без паролей, если нет прав администратора.

## Умный подбор, видеокарта и CS2

Программа сначала составляет портрет ПК (`engine\Hardware.ps1`): видеокарта и её производитель, две видеокарты (ноутбук), ноутбук/батарея, SSD или HDD, объём и частота памяти, частота монитора, интернет по кабелю или Wi-Fi, путь к CS2 и её видеонастройки (`cs2_video.txt`). Только чтение.

**Подбор** (`engine\Smart.ps1`). У действия в `data\actions.json` могут быть поля:

| Поле | Смысл |
|---|---|
| `requires` | без этого действие не применяется вообще (например `{ "gpu": "nvidia", "cs2": true }`) — в списке «не подходит» |
| `skipIf` + `skipWhy` | подходит, но этому ПК не рекомендуем (например, ноутбук — не трогаем батарею) |
| `boostIf` + `boostWhy` | рекомендуем этому ПК, даже если эффект в среднем низкий (например, две видеокарты) |

Условия: `gpu`, `laptop`, `hybridGpu`, `ssd`, `cs2`, `hags`, `ramGbMin`, `ramGbMax`, `cpuCoresMax`. Во вкладке «Игры» колонка «Для вашего ПК» объясняет решение, ★ — подобрано под этот ПК, кнопка «Подобрать под мой ПК». «Ускорить компьютер» показывает только то, что ещё не настроено.

**Видеокарта.** Профиль драйвера NVIDIA для `cs2.exe` меняется напрямую через `nvapi64.dll` (`engine\Nvidia.ps1`, раскладка структур сверена с NVIDIA Profile Inspector) — без скачивания программ. Шаг `{ "type": "nvidia", "exe", "id", "value" }`. Перед записью читается старое значение; откат (журнал, раздел `nvidia`) возвращает его или сбрасывает настройку «как в драйвере». Настройки: управление питанием «максимальная производительность», режим низкой задержки, V-Sync выкл. (по желанию). Для Windows: CS2 на мощной видеокарте (`UserGpuPreferences`, подстановка `{cs2exe}`), HAGS.

**CS2** (`engine\Cs2.ps1`). `cs2cfg` пишет в `autoexec.cfg` только свой блок между отметками `// >>> pckit` и `// <<< pckit` — строки пользователя не трогаются; если файла не было, откат его удаляет. `cs2launch` дописывает недостающие параметры запуска в `userdata\<id>\config\localconfig.vdf` (бэкап в журнале); при открытом Steam не применяется — Steam перезаписал бы файл.

**Проверка результата.** Каждое применение запоминает границу партии (`last-batch.json`). «Результат» выдаёт вердикт «помогло / нет разницы / стало хуже» по FPS (порог ±3%) и задержкам драйверов; если стало хуже — предлагает откатить только последнюю партию (`Restore-PckitJournal -Since`), ранние изменения остаются.

**Советы в «Проверке»:** монитор не на максимальной частоте, частота в CS2 ниже монитора, V-Sync/Reflex/оконный режим в CS2, XMP/EXPO выключен, каналы памяти (по подписям слотов), HDD, батарея, Wi-Fi, CS2 не на мощной видеокарте.

Тесты: `tests\Smart.Tests.ps1` (подбор, autoexec, vdf, откат партии, журнал NVIDIA, вердикт, советы) — без изменений системы.

**Старые версии драйверов** («Чистка», риск «осторожно», по умолчанию выключено). Сторонние пакеты DriverStore группируются по исходному .inf + производитель + класс; новейшая версия, дубли той же версии и всё, что назначено устройствам (Win32_PnPSignedDriver), остаются. Перед удалением — список с версиями и размером; удаление pnputil /delete-driver без /force. Необратимо. «Проверка» сообщает, сколько их и сколько места занимают.

## Удобство (ноябрь 2026)

- **Главная:** большая карточка «Всё сразу» (проверка → настройки под железо → безопасная чистка → проверка свежего драйвера → список «сделайте руками» → предложение перезагрузиться), строка «Ваш ПК: …» и ссылка «Дальше: …» — один следующий шаг. Карточки: Ускорить, Почистить, Проверить, Результат, Сеть для CS2, Отчёт для друга.
- **После перезагрузки** pckit сам предлагает сравнить «до» и «после» (ждёт 3 минуты после загрузки Windows, чтобы замер был честным).
- **Результат:** вердикт крупно в шапке; число процессов (±10) и служб (±4) больше не помечается «хуже» из-за обычных колебаний.
- **Игры:** группы (Видеокарта, CS2, Питание…), фильтр «Все / Подобрано под мой ПК / Ещё не включено / Мифы», поиск, подсказки при наведении.
- **Проверка:** «Исправить / Перейти / Открыть настройки» ведёт к месту исправления (вкладка, раздел или страница Параметров Windows); кнопки «Свежий ли драйвер?» и «Отчёт для друга».
- Визуальные стили Windows включаются в начале `pckit-ui.ps1` — иначе не работают группы в списках.

**Свежий драйвер** (`engine\Driver.ps1`): модель ищется в справочнике NVIDIA (`lookupValueSearch.aspx?TypeID=3`, ID модели и серии), последняя версия — через `AjaxDriverService.php`. Ничего не скачивается: открывается официальная страница драйвера.

**Сеть для CS2** (`engine\Network.ps1`, вкладка «Сеть»): пинг до роутера; ближайшие узлы Steam Datagram Relay из `ISteamApps/GetSDRConfig?appid=730` (по 40 пингов: медиана, скачки, потери); по желанию — пинг, когда идёт закачка (3 потока с speed.cloudflare.com, до 300 МБ, только в память). Выводы: виноват Wi-Fi/дом, провайдер или раздувание очереди в роутере (совет: SQM / пауза закачек).

**Отчёт для друга** (`engine\Share.ps1`): HTML-файл на Рабочем столе — железо, драйвер (и есть ли новее), видео-настройки CS2, замечания, что включено и что стоит включить, последняя проверка сети и FPS. Имя пользователя, имя ПК и путь к профилю вырезаются.

Тесты: `tests\Extras.Tests.ps1` (разбор ответов NVIDIA, статистика и выводы сети, отчёт без личных данных, «шум» в сравнении).

## Для работы и готовность к раздаче (v2.2.0)

- **«Для работы»** (карточка на главной, `engine\Work.ps1`, `data\work-apps.json`, `data\work-profile.json`): находит установленные Adobe, Autodesk, Office/Teams, мессенджеры, SketchUp/ArchiCAD/Blender/Corel; включает рабочий набор настроек (без игровых, CS2 и экспертных; ноутбук/HDD — по skipIf); чистит общий мусор и безопасные кэши этих программ; крупное и спорное (журналы и CollaborationCache Revit, кэш OneDrive, кэш Telegram, старые установщики в «Загрузках», Windows.old) только показывает с размером и предлагает открыть папки. Действие `work.gpu` закрепляет найденные рабочие exe за мощной видеокартой (шаг `workgpu`, журналируется).
- **Ошибки:** любое исключение в окне — понятное сообщение и запись в `%LOCALAPPDATA%\pckit\logs`; «Сохранить лог для разработчика» (zip на Рабочий стол) — в «О программе» и в окне ошибки. Ошибки фоновых задач тоже пишутся в лог.
- **Готовая программа:** версия в заголовке и «О программе» (`$script:PckitAppVersion` в `pckit-ui.ps1`), защита от второго экземпляра, приветствие при первом запуске, «Удалить pckit с этого ПК» (по желанию сначала откатывает все изменения).
- **Экраны:** окно подгоняется под рабочую область (1366×768, масштаб 150%), главная прокручивается, минимальная ширина 1060.
